# DeskNoise

Windows 트레이 상주형 음원 생성기입니다. 톤과 잡음을 최대 세 겹까지 동시에
재생해서, 배경으로 깔아 둘 소리를 직접 만들 수 있습니다.

English: [README.md](README.md)

## 기능

- **음원 다섯 가지** — 삐 소리(사인파), 바람 소리(좁은 대역 노이즈), 라디오
  잡음(화이트 노이즈), 빗소리(핑크 노이즈), 파도 소리(브라운 노이즈)
- **소리 레이어 세 개**가 함께 재생됩니다. 레이어마다 음원, 주파수, 대역폭,
  음량, 좌우를 따로 조정합니다
- **모든 잡음에 대역 필터**가 걸립니다. 대역폭을 좁히면 지정한 주파수 주변만
  남고, 전체로 열면 원래의 넓은 잡음 그대로입니다
- **흔들림** — 순음에서 아주 가까운 두 주파수를 겹쳐 음량이 물결치게 합니다.
  단조로운 톤이 덜 지루해집니다
- **재생과 휴식 반복** — 정해진 시간만큼 재생하고 쉬는 것을 반복합니다
- **프리셋** 저장
- **트레이 상주**, `Ctrl+Alt+M` 으로 어디서나 재생과 정지
- **한국어와 영어**, Windows 표시 언어를 따라갑니다

## 요구 사항

Windows 10 이상. 별도로 설치할 런타임이 없습니다. 정적 CRT로 연결한 단일
실행 파일입니다.

## 빌드

Visual Studio 2022의 C++ 데스크톱 워크로드가 필요합니다. `cl.exe` 를 직접
호출하므로 프로젝트 파일이나 CMake는 없습니다.

```
build.bat         릴리즈, build\DeskNoise.exe 생성
build.bat debug   디버그, build\DeskNoise-debug.exe 생성
```

Visual Studio 설치 경로가 기본값과 다르면 `build.bat` 위쪽의 `VS` 경로를
변경하십시오.

## 설정 파일

설정과 프리셋은 `%APPDATA%\DeskNoise\config.ini` 에 저장됩니다.

## 명령줄 옵션

| 옵션 | 동작 |
| --- | --- |
| `/tray` | 창 없이 트레이에서 시작합니다. |
| `/lang=ko`, `/lang=en` | Windows 설정 대신 지정한 언어를 사용합니다. |

## 소스 구성

| 파일 | 내용 |
| --- | --- |
| `src/main.cpp` | 창, 레이아웃, 레이어 편집, 프리셋, 트레이 아이콘, 설정 |
| `src/audio.cpp`, `src/audio.h` | WASAPI 공유 모드 출력과 음원 생성 |
| `src/i18n.h`, `src/i18n.cpp` | 모든 UI 문자열, 한국어와 영어를 나란히 관리 |
| `src/app.rc`, `src/resource.h` | 아이콘, 매니페스트, 버전 정보, 프리셋 이름 대화상자 |
